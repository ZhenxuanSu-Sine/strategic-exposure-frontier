# Expected baseline interpretation

The baseline scripts are designed to establish feasibility, not publication-level novelty.

- E18 should exactly reproduce an unbounded peak/workload gap family.
- E19 should usually show that workload and peak budgets select different strategies over some budgets.
- E20 should show occupancy changes rescale the workload frontier.
- E21 is intentionally a real test: it may or may not find a payoff-preserving exposure gap in Tic-Tac-Toe. A null result is useful and should be preserved.
- E22 should reveal multiple optimal `(p_hard, queries)` regimes on the joint resource surface.
